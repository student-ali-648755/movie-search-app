# 🎬 Movie Search App

A simple Movie Search App built with **HTML, CSS, and JavaScript** using the **OMDb API**.

## 🚀 Features

* 🔍 Search movies by title
* 🎬 Display movie poster and details
* ⭐ IMDb Rating
* 🎭 Genre
* 🎬 Director
* 👥 Actors
* 📝 Plot
* 🌙 Dark Mode
* 💾 Theme saved with Local Storage
* 🕒 Recent Search History
* ⌨️ Search using Enter key
* ❌ Error handling for invalid movie names

## 🛠 Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Fetch API
* Async/Await
* Local Storage
* OMDb API
